# 官网浏览器采集扩展

这个扩展由你在已经能正常打开的官网页面主动启动，把器械页面和图片保存成一个 `.gymcapture.json` 文件，交给健身房地图的采集文件导入入口。无需手工逐张保存图片。

## 安装与使用

1. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`，启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，选择此 `browser-capture` 文件夹。
3. 正常打开官网器械目录页或单个产品页。点击工具栏中的本扩展，再点“开始采集”，在浏览器提示中授权当前官网及页面已发现的图片来源域名。
4. 保持浏览器运行。扩展会顺序打开产品标签页，读取公开内容后关闭自己创建的标签页，保留你的原始页面。
5. 保存导出的文件，在健身房地图导入该采集文件，检查候选和分类后确认保存。关闭扩展小面板不会停止采集；要结束当前采集，重新点开扩展并点击“停止并导出已采集内容”。

## 范围与限制

- 当前页面加同站直接产品链接，合计最多 50 页；不会递归遍历整个网站，也不会自动点击下一页。导航、分类页及明显配件链接会被筛除，非标准网页可能需要在单个产品页分别启动。
- 每个器械保存对应列表条目的 1 张图片和详情页最多 3 张图片，按来源链接去重，列表图片优先；列表中没有对应图片时仍取详情页最多 3 张。详情读取失败时保留列表中的名称与图片并记录失败。每图最多 20 兆字节；每页页面内容最多 4 兆字节，文件最多 64 兆字节，解码后的页面和图片合计最多 48 兆字节。达到限制的项目会写入失败清单，已成功内容仍可导出。
- 当前页未出现过的图片域名不会获得隐式授权。如果图片失败提示缺少授权，可在对应产品页重新启动，授权浏览器提示的图片来源。图片请求不携带账户凭据，不尝试读取登录后专用图片。
- 不读取 Cookie、浏览器存储或表单值；去除表单、可编辑内容、脚本及内嵌框架，只保留商品结构化公开事实。不要在账户中心、订单或其他私人页面启动。
- 发现登录、验证码、访问拒绝或错误页面会记录失败；不会把这些页面作为商品成功导入，也不会绕过验证。需要人工正常打开网页后再决定是否采集。
- 文件只下载到本机，不上传到服务器。未打包为浏览器商店安装项，需要按上面的开发者模式加载。

## 验证

`node tests/browser-capture-extension.cjs` 在独立测试浏览器和本机测试网站运行真实扩展后台、标签导航、页面提取和图片打包。测试专用副本预先授予本机站点权限，并拦截系统保存对话框检查文件内容；生产扩展仍由用户通过浏览器授权和保存。

已验证列表图片与具体器械链接精确配对、列表 1 张加详情 3 张、同图去重、详情拒绝时保留列表信息并记录错误，以及表单与脚本私人字段排除、商品结构化内容保留、配件不跟随、自动创建标签关闭及原始标签保留。未使用真实 Full Circle Padding 网站运行测试。
