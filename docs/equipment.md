# 器械分类与品牌目录批量导入

更新日期：2026-09-10。对应版本 1.3.0。源码回归、真实品牌目录验证及打包程序复核均已完成，完整安装包位于 release/NationalGymMap-Setup.exe。

## 分类与档案

| 顶级类型 | 保存值 | 适用子字段 |
| --- | --- | --- |
| 固定器械 | `fixed` | 必选部位及对应应用标签；可选插片／挂片 |
| 有氧器械 | `cardio` | 无更深分类 |
| 自由力量 | `free_weight` | 必选哑铃 `dumbbell`、杠铃 `barbell`、史密斯 `smith` 或力量架 `rack` |
| 龙门架 | `cable_station` | 无更深分类 |

固定器械保持多部位、多标签，不将旧多选信息压缩为单值。胸对应推胸、夹胸；肩对应肩推、中后束；背对应背下拉、背后拉；腿对应近固蹬、远固蹬、髋伸、髋旋、腿屈伸、腿弯举；核心对应脊柱屈、脊柱伸；手臂对应二头、三头。

手动新增和单页导入需要主动选择类型。切换类型时清除不适用部位、标签、负重类型或自由力量子类。器械名称、型号、品牌、图片、来源、备注及原有场馆关联独立保留。来源字段包括 `sourceType`、`sourceUrl`、`sourceDate`，核实字段包括 `verificationStatus`、`verifiedBy`、`verifiedAt`，同时保存创建和更新日期。`productUrl` 和 `imageSource` 继续保留兼容。

## 候选工作台

选择品牌并扫描官网目录或系列页，先生成候选，随后顺序读取产品详情。队列控制并发和请求间隔，单页失败不会终止整个批次。候选中保留图片来源、名称、型号、系列、描述、官网分类、建议分类及错误；规则建议必须由用户复核。扫描和编辑候选不写入正式器械集合。

批次保存在数据文件的 `importBatches`，关闭窗口或重启后继续处理。候选状态包含待导入、已导入、暂缓、忽略、读取失败、疑似重复和资料不足。可多选设置分类、部位、标签和状态；可打开来源网页、单条重试或使用浏览器辅助读取。暂缓和忽略决定按品牌与来源记忆，重新扫描时保留。

最终确认前展示新增、补充、重复、暂缓、忽略、失败及待下载图片数量。品牌与型号优先识别确定重复，品牌与规范名称提示疑似重复，来源辅助匹配；同批候选也参与查重。用户可补充已有记录、作为新器械或忽略。补充默认仅填空字段，原有非空名称、图片和场馆关联保留。确认后整批校验并原子保存，图片下载失败仍允许保留基本档案并记录图片失败状态。

## 官网错误与图片

响应保留状态和原因，区分拒绝访问、页面不存在、限流、服务异常、超时、网络错误及解析失败。HTTP（Hypertext Transfer Protocol，超文本传输协议）403 不等于永久无法读取，也不能当作成功；辅助浏览器和 PDF（Portable Document Format，便携式文档格式）单页导入是独立兜底。不会自动绕过验证码、安全挑战或访问限制。自动文字识别和批量文档导入不在此次范围。

图片按文件内容识别并存入本地图片目录。此次增加 AVIF（AV1 Image File Format，AV1 图像文件格式）内容识别，核对文件类型盒中的品牌标识，不依赖文件扩展名或任意正文匹配，减少官网现代图片格式被错误拒绝。

## 旧数据迁移和还原

保留 `schemaVersion: 1`，扩展标识为 `metadata.equipmentModelVersion: 1`。读取未迁移数据库时，旧部位代码或中文胸、肩、背、腿、核心、手臂转换为现有部位代码；兼容旧 `body`、`applicationTag` 及 `part`、`parts`、`tags`。有可靠部位或标签的记录识别为固定器械，无法判定则保留未分类并标记 `needs_review`。旧缺项档案允许加载及修改非分类字段；主动改分类时需要满足新规则。原记录标识、图片引用、品牌、链接和场馆关联不变。

迁移前复制完整数据目录到 `backups/equipment-model-*`，排除已有备份，逐文件校验哈希成功后才替换正式数据库；快照路径记录在 `metadata.equipmentMigrationBackup`。磁盘不足、复制失败或校验失败时不会写入迁移后数据库。

需要还原目录快照时，先复制该完整快照至一个新的独立数据目录，再通过程序的重新关联流程选择它；当前数据可用时可在独立配置启动中关联该目录，避免覆盖当前档案。关联后当前程序会再次执行兼容迁移并保留新的迁移前快照。备份目录中的原始文件可供旧版程序读取，不必手改记录。

恢复旧压缩备份时，先验证清单和全部文件，再保存当前目录的安全备份，并将原始压缩文件额外复制到 `backups/equipment-model-source-*.zip`。该原始压缩文件可通过正常恢复备份操作重新使用；恢复失败保留当前数据并回退。
