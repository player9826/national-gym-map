# 全国健身房地图 1.5.2

器械库新增品牌范围统计、部位二级筛选、品牌系列和指定字段搜索；场馆的器械选取及已关联列表使用相同筛选规则。

- 顶部各类型数量只随品牌变化，筛选结果另计；返回顶部保留浏览条件。
- 胸部可进一步筛选推胸、夹胸；增加小臂、小腿及可复用的自定义部位，推肩兼容旧分类。
- 系列按品牌独立填写、建议、展示、搜索和共享，允许留空。
- 场馆器械筛选不会清除已勾选项目或解除已有关系。

本次同时包含 1.4.0 之后尚未公开的更新：场馆独立详情弹窗、局部主题色、关联图片放大、紧凑品牌字母标识、网站导入三张候选图片、确认保存后入库、批量删除候选，以及随程序提供的浏览器采集扩展。

网站读取仍受实际访问条件限制。Full Circle Padding 尚未完成实站整批成功验收；可在普通浏览器正常打开页面后，用采集扩展整体导出详情与图片，再在应用确认导入。Scrapling 已完成本地接入评估，未作为默认运行依赖。

升级保留独立的数据目录。共享新分类的维护端及订阅端请使用 1.5.2 或更新版本；现有公共资料不因软件升级而改动。已安装用户可在“数据与设置”中检查更新，或下载本页安装包升级。

发布前已通过 65 项单元测试及分类、关联、保存重启等桌面回归；打包程序另行复核。安装包、增量更新辅助文件、更新清单和校验文件共同发布。
