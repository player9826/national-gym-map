# 公开只读网页版

正式网址：[全国健身房地图](https://player9826.github.io/national-gym-map/)。2026-09-22 完成首次发布及线上验收。

网页面向公众浏览场馆、器械及品牌分类，支持手机布局、场馆与器械双向查看和详情分享。维护者继续通过桌面程序采集与编辑。网页没有账号、个人打卡、投稿或多人编辑。

## 本地预览

在项目根目录运行 `npm.cmd run build:web`，再运行 `npm.cmd run preview:web`，打开终端给出的本机网址。这里 npm（Node Package Manager，Node.js 包管理器）用于运行项目脚本。

网站产物在 `dist-web/`；桌面产物仍在 `dist/`。构建网页不会生成安装包或修改桌面版本。

## 更新网站与资料

- 修改网页代码并通过相关检查后，推送到主分支，由 `.github/workflows/pages.yml` 测试、构建并部署 GitHub Pages。
- 更新公开资料时，从桌面程序导出完整共享快照，审查 `shared/` 中的资料与图片后一起发布。不要单独修改资料文件后保留旧清单校验值。
- 分享的详情链接使用地址中的片段保存场馆或器械标识；刷新和直接打开均可恢复详情。已撤下或不存在的资料会提示返回浏览。
- 网站代码和数据由同一次部署发布。打开网页或点击“更新资料”会读取当前发布清单；现有页面不会主动定时刷新。
- 桌面安装包仅在推送版本标签或手动运行桌面工作流时构建，默认生成发布草稿。

## 数据边界与图片

`scripts/build-web.cjs` 校验共享资料及图片的大小、内容摘要和路径，再用现有共享字段白名单生成网站资料。个人到访记录、备注、原始测评、设置和导入草稿不在网站快照内。

图片按比例生成最长边 480 的列表图和最长边 1600 的详情图，小图不放大。重新编码移除原图元数据，内容摘要作为文件名；浏览器按需加载，缩略图失败时尝试详情图。放大预览使用详情图。

网站数据包含 `data/manifest.json`、`data/catalog.json` 和 `data/images.json`。浏览器校验两个数据文件，遇到网络失败、清单损坏或部署期间版本不一致会提示重新加载，不会混用部分新资料。源文件字节由 `.gitattributes` 保留，避免不同操作系统改变换行符后破坏摘要。

## 验证

- `npm.cmd test`：数据、业务与网站构建校验。
- `node tests/web.cjs`：对构建后的真实网站运行浏览器验收，自启本机临时服务器；支持已安装的 Chromium、Microsoft Edge 或 Google Chrome。
- `npm.cmd run build` 后执行 `node tests/desktop.cjs`：使用隔离档案验证共用界面对桌面功能的兼容。

网页验收报告及截图在 `test-results/web/`。公开发布前核验 GitHub Pages 工作流、网页和资料请求成功，再验证线上详情链接与图片。

## 运行限制

全国行政区数据随网站提供，街道底图来自外部服务，访问质量取决于使用者网络。未承诺离线访问、搜索引擎逐条收录或微信分享卡片。公开资料只包含现有审核快照，不推断缺失的评分、简介或器械分类。
